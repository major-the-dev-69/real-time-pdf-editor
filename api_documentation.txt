1. REST API ENDPOINTS (REQUIRED FIELDS ONLY)
--------------------------------------------------------------------------------

[1.1] AUTHENTICATION

1. User Login
   POST /api/v1/auth/login
   Request Body:
   {
     "username": "agent01",
     "password": "Password123"
   }
   Response Body (200 OK):
   {
     "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
     "userId": "usr_98765",
     "role": "agent"
   }

2. Request Forgot Password (Send OTP)
   POST /api/v1/auth/forgot-password
   Request Body:
   {
     "mobileOrEmail": "9876543210"
   }
   Response Body (200 OK):
   {
     "status": "success",
     "message": "OTP sent successfully",
     "otpId": "otp_12345"
   }

3. Verify OTP
   POST /api/v1/auth/verify-otp
   Request Body:
   {
     "otpId": "otp_12345",
     "otp": "123456"
   }
   Response Body (200 OK):
   {
     "status": "success",
     "message": "OTP verified successfully",
     "resetToken": "rst_tok_998877"
   }

4. Reset Password
   POST /api/v1/auth/reset-password
   Request Body:
   {
     "resetToken": "rst_tok_998877",
     "newPassword": "NewPassword123"
   }
   Response Body (200 OK):
   {
     "status": "success",
     "message": "Password reset successfully"
   }

2. WEBSOCKETS REAL-TIME DATA SYNCHRONIZATION (REQUIRED FIELDS ONLY)
--------------------------------------------------------------------------------
WS Connection URL:
ws://domain.com/ws/pdf-editor?pdfId={pdfId}&token={token}

---

[2.1] CLIENT -> SERVER MESSAGES (SENDING REAL-TIME EDITING DATA)

1. Join Live Editing Session
   {
     "action": "JOIN_SESSION",
     "pdfId": "pdf_1",
     "userId": "usr_98765"
   }

2. Send Draw Stroke Line
   {
     "action": "DRAW_STROKE",
     "pdfId": "pdf_1",
     "pageNumber": 1,
     "points": [
       {"x": 120.5, "y": 240.2},
       {"x": 125.0, "y": 245.8}
     ],
     "color": "#FF0000",
     "strokeWidth": 4.0
   }

3. Send Text Annotation
   {
     "action": "ADD_TEXT",
     "pdfId": "pdf_1",
     "pageNumber": 1,
     "annotationId": "txt_1001",
     "x": 150.0,
     "y": 300.0,
     "text": "Approved Layout",
     "color": "#0000FF",
     "fontSize": 18.0
   }

4. Erase Annotation at Coordinates
   {
     "action": "ERASE_ANNOTATION",
     "pdfId": "pdf_1",
     "pageNumber": 1,
     "x": 150.0,
     "y": 300.0
   }

5. Undo Last Action
   {
     "action": "UNDO",
     "pdfId": "pdf_1",
     "pageNumber": 1
   }

6. Clear Page Annotations
   {
     "action": "CLEAR_ALL",
     "pdfId": "pdf_1",
     "pageNumber": 1
   }

---

[2.2] SERVER -> CLIENT MESSAGES (RECEIVING BROADCAST DATA)

1. Broadcast New Draw Stroke Line
   {
     "event": "STROKE_ADDED",
     "userId": "usr_98765",
     "pageNumber": 1,
     "points": [
       {"x": 120.5, "y": 240.2},
       {"x": 125.0, "y": 245.8}
     ],
     "color": "#FF0000",

   }

2. Broadcast New Text Annotation

     "userId": "usr_98765",
     "pageNumber": 1,
     "annotationId": "txt_1001",
     "x": 150.0,
     "y": 300.0,
     "text": "Approved Layout",
     "color": "#0000FF",

3. Broadcast Erase Action

     "y": 300.0
   }

4. Broadcast Clear Page
   {
     "event": "PAGE_CLEARED",
     "userId": "usr_98765",
     "pageNumber": 1
